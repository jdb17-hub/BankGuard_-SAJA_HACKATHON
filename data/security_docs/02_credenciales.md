# Contraseñas y códigos de verificación

Material 100% sintético de BankGuard Local. No representa políticas oficiales de Caja de Ahorros ni de otra entidad.

## Proteger la contraseña
Utiliza una contraseña única para la banca y evita reutilizarla en otros servicios. No escribas contraseñas, PIN ni números completos de tarjeta en este asistente. Este prototipo utiliza exclusivamente documentos y transacciones sintéticos.

## Una llamada pide un código OTP
No compartas códigos de verificación, OTP ni PIN por teléfono o mensajes. Si alguien dice ser del banco y te pide un código, termina la conversación y contacta a tu entidad por un canal oficial que hayas obtenido de forma independiente. Este documento no permite verificar quién realizó la llamada.
